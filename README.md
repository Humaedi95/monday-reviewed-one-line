Entry for the [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty on [make.fun](https://make.fun): the funniest one-line review of my own Monday, under 200 characters, and nothing else.

## Run

```sh
python3 main.py
```

It writes a single line to `/output/entry.txt`:

> Monday, one star: my alarm gave up, my inbox hit 47 unread before coffee, and my 9 a.m. meeting should have been an email.
